# Simple Daily Notes

A streamlined interface to edit multiple daily notes in a single continuous inline page, providing an experience similar to Roam Research's daily note view.

# Features

- **Unified View**: Edit multiple daily notes in a single, continuous inline page.
- **Advanced Filtering**: View and filter notes by various time ranges:
    - Week, Month, Year, Quarter
    - Last Week, Last Month, Last Year, Last Quarter
    - All notes
    - Custom date range
- **Versatile View Modes**:
    - **Daily Notes mode**: View your standard daily notes.
    - **Folder mode**: View all notes from a specific folder.
    - **Tag mode**: View all notes containing a specific tag.
- **Sorting Options**:
    - Sort by creation time (newest/oldest first).
    - Sort by modification time (newest/oldest first).
- **Customization**:
    - Hide frontmatter in daily notes.
    - Hide backlinks in daily notes.
    - Automatically create and open the editor on startup.
- **Presets**: Save custom folder or tag selections as presets for instant access.
- **Keyboard Navigation**: Navigate between notes using arrow keys.
- **Contextual Actions**: Right-click on folders in the file explorer to instantly open all notes from that folder in the editor.

# Installation

1. Clone this repository and follow the build instructions.

# Settings

- **Hide frontmatter**: Toggle to hide frontmatter in daily notes.
- **Hide backlinks**: Toggle to hide backlinks in daily notes.
- **Create and open Simple Daily Notes on startup**: Automatically create today's daily note and open the editor when Obsidian starts.
- **Presets**: Manage and access your saved folder and tag presets.

# Usage

1. Click the calendar icon in the left ribbon or use the command "Open Simple Daily Notes".
2. Use the action buttons in the view to select time ranges, change view modes, or adjust sorting.
3. Save your current view as a preset for future use.
4. Right-click any folder in your file explorer to open its contents in the editor.
